## Deploy to Vercel

```bash
# From this directory
vercel --prod
```

Or connect via GitHub:
1. Create repo for this folder
2. Push to GitHub
3. Import to Vercel from [vercel.com/new](https://vercel.com/new)
4. Add domain `piagetsupplies.co.ke` in Vercel dashboard

## Local Testing

```bash
start index.html
```
